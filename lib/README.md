# lib/ — 승격을 통과한 코드만 있는 곳

이 폴더는 **git이 추적하는 3층**이다. 여기 들어오려면 `docs/승격기준.md`의 관문 두 개를
모두 통과해야 한다.

## 여기 두는 것

- 둘 이상의 분석이 실제로 함께 쓰는 **재사용 가능한 계산**.
- 데이터를 **인자로 받는** 함수. 특정 분석 폴더의 파일 경로를 알고 있으면 안 된다.

## 여기 두지 않는 것

- **드라이버 스크립트** — "어떤 값으로, 어떤 순서로 이 함수들을 불렀는가"는 각 분석
  폴더(`out/<분석명>/run.py`)에 남는다. 그게 그 분석의 정체성이다.
- 아직 한 분석에서만 쓰는 코드. 의존성이 0이어도 그대로 분석 폴더에 둔다.
  잃으면 안 되는 것이면 `bootstrap/`에 사본을 남긴다.

## 늘어나지 않는 것이 정상이다

라이브러리가 빠르게 커지고 있다면 승격 기준이 느슨해졌다는 뜻이다. 이 폴더의 크기는
성과 지표가 아니다 — **유지 비용**이다.

`tests/`에도 같은 기준이 적용된다. 그 폴더는 이 폴더를 지키는 곳이므로, 한 분석
안에서만 쓰는 코드의 테스트는 그 분석 폴더(`out/<분석명>/tests/`)에 둔다.
