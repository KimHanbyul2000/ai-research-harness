# 분석 폴더 규칙 — 세 파일이 항상 같이 있다

## 전제

> **코드는 틀리면 멈추지만, 분석은 틀려도 숫자가 나온다.**

이 골격의 모든 규칙이 이 한 문장에서 나온다. 분석의 실패 양상은 정지가 아니라
**조용히 틀린 채로 계속 가는 것**이다. 그래서 속도보다 "나중에 틀렸음을 확인할 수
있는 상태"를 먼저 만든다.

## 폴더 하나 = 분석 하나

```
out/YYYYMMDD_<주제>/
├── 00_설계목표.md   ← 실행 '전'에 쓴다
├── run.py           ← 실행 코드
├── 01_결과해석.md   ← 실행 '후'에 쓴다
├── data/            ← 산출 데이터 (추적 안 함)
└── figures/         ← 산출 그림 (추적 안 함)
```

라이브러리(`lib/`)는 import해서 쓰고, 이 폴더 안에 라이브러리 코드를 두지 않는다.
분석이 끝나면 폴더째 `archive/`로 옮긴다.

## 00_설계목표.md — 실행 전에 쓴다

**코드보다 먼저 존재해야 한다.** 이게 이 규칙의 핵심이다. 실행 후에 쓰면 결과에 맞춰
목적이 재구성되고, 그러면 "무엇을 확인하려 했는가"가 사라진다.

담는 것:

| 항목 | 내용 |
|---|---|
| 목적 | 무엇을 확인하려 하는가. 한 문장 |
| 왜 하는가 | 지금 이걸 하는 계기. 누구의 지적인지 포함 |
| 방법 | 대상·데이터 출처·판정 기준. **새 데이터를 만드는지 기존 데이터를 다시 보는지 명시** |
| 정한 것 \| 값 \| 이유 | 파라미터마다 **왜 그 값인지**를 표로. 이유 칸이 비면 그 값은 아직 정해진 게 아니다 |
| 산출물 | 어떤 파일이 나오는가. 재현 명령 한 줄 |

## run.py — 재현 명령 한 줄로 끝나게

- 입출력 경로를 **자기 폴더로 명시 지정**한다. 기본값에 의존하지 않는다.
- 라이브러리는 import만 한다.
- 판정 로직이 이전 분석과 같아야 한다면 **그 사실을 코드로 단언한다**(아래 참조).

## 01_결과해석.md — 결론을 맨 위에

담는 것: 결론 → 방법(설계목표와 실제가 다르면 그 차이) → 결과 → 한계.

**결과 절에 반드시 들어가야 하는 세 가지가 있다.**

### ① 탈락 사유를 단계별로 분해해 남긴다

조건을 만족한 대상만 적고 끝내지 않는다. **떨어진 대상이 어느 단계에서 왜 떨어졌는지**를
남긴다.

> "없다"가 아니라 "어디서 떨어졌나"가 남아야, 다음에 기준이 또 바뀔 때 처음부터 다시
> 돌지 않는다.

기준은 바뀐다. 그때 탈락 사유가 없으면 전체를 다시 계산해야 하고, 있으면 해당 단계만
다시 본다.

### ② 판정 기준이 바뀌었으면 커버리지를 감사한다

기준을 고친 뒤 **어디까지 다시 적용했는지**를 표로 남긴다.

| 언제 | 무엇을 봤나 | 대상 범위 |
|---|---|---|
| … | … | 전체 / 부분집합(무엇) |

기준 변경 후 일부에만 재적용하고 넘어가는 것은 흔한 사고다. 본인도 모른다는 게
문제다. 이 표가 **"확인하지 않은 것"과 "확인해서 없는 것"을 구분**해준다.

### ③ 결론의 취약성을 적는다

결론이 소수의 데이터포인트에 걸려 있으면 그 사실을 남긴다. 경계 근처 값, 한두 개
차이로 갈린 판정 같은 것들이다. 강한 결론처럼 보이는 약한 결론이 가장 위험하다.

## 재분석은 과거 결론을 재현해야 한다

판정 기준을 바꿔 다시 돌릴 때, **옛 기준으로 돌리면 이전 결론이 그대로 나오는지**를
코드로 단언한다.

```python
assert set(classify(data, old_criteria)) == PREVIOUS_RESULT, \
    "옛 기준 재현 실패 — 기준 변경 외의 무언가가 함께 바뀌었다"
```

재현되지 않으면 실행이 멈춘다. 기준만 바꿨다고 생각했는데 다른 것도 바뀐 경우를
잡는 장치다. 회귀 테스트를 코드가 아니라 **분석 결론**에 거는 것이다.

## 폐기분은 삭제하지 않는다

버린 분석은 지우지 말고 `archive/` 아래 날짜 폴더로 옮긴다. 되살릴 일이 생기고,
무엇을 왜 버렸는지가 다음 판단의 근거가 된다.
