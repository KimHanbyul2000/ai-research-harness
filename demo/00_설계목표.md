# 설계목표 — 데모 뷰어

> 이 폴더는 이 저장소의 규칙을 **이 저장소 자신에게 적용한** 예다. 뷰어를 만들기 전에
> 이 문서를 먼저 썼다([승인 게이트](../docs/승인게이트.md) 게이트 1).

## 목적

`.html`이 **검증 단계의 도구**라는 주장과, 시각화 오류가 **테스트를 통과한 채로 틀린다**는
주장을 글이 아니라 **조작으로** 확인시킨다.

## 왜 하는가

두 문서가 말로만 남아 있으면 읽는 사람이 "그런 일이 실제로 있나"에서 멈춘다.

- [`docs/포맷별_역할.md`](../docs/포맷별_역할.md) — `.png` 대신 `.html`이 필요한 신호 네 가지
- [`docs/오답노트.md`](../docs/오답노트.md) — 패턴 1 · 5 · 7

## 방법

**새 데이터를 만들지 않는다.** 페이지 안에서 고정 시드로 생성한다 — 외부 파일도 통신도
없다. 값·조건명·단위는 전부 가상이다.

> 이 데모뿐 아니라 **원래 워크플로의 데이터도 측정값이 아니라 시뮬레이션이 만든 값**이다.
> 생성 규칙이 코드에 있으므로 어떤 값이 왜 그렇게 나왔는지를 **원리까지 거슬러 올라가
> 물을 수 있다.** 실측 데이터였다면 원인이 데이터 바깥에 있어 "이런 경향이 있다"에서
> 멈춘다 — 자세한 것은 [README의 전제 절](../README.md#전제--데이터를-우리가-만든다).
> 여기서는 그 성질을 그대로 써서, 틀린 판과 고친 판이 **같은 데이터**를 쓰되 그리는
> 기준만 다르게 했다. 차이의 원인이 데이터가 아니라 그리는 코드에 있다는 것이 보여야
> 패턴 시연이 성립한다.

| 정한 것 | 값 | 이유 |
|---|---|---|
| 탭 구성 | 2개 (오답노트 실연 / 데이터 탐색) | 두 주장이 서로 다른 것을 보여준다. 한 화면에 합치면 둘 다 흐려진다 |
| 외부 라이브러리 | **쓰지 않음** (순수 JS + Canvas) | 자기완결 파일 하나여야 한다. 링크가 죽으면 결과도 죽는다 |
| 데이터 생성 | 고정 시드 PRNG, 페이지 내부 | 누가 언제 열어도 같은 화면. 재현이 성립해야 검증 도구다 |
| 색 | CSS 변수 단일 출처 | 오답노트 패턴 5의 대응책을 코드로 보여주기 위해 |
| 배경 | 밝은 단색 | 발표 투사 환경 기준 |
| 규모 | 세포 13 × 조건 4 × 10주기 | 한 화면에 들어가면서 겹침 문제(패턴 7)가 드러나는 최소 크기 |

### 탭 1 — 오답노트 실연

패턴마다 **틀린 판 / 고친 판**을 토글한다. 핵심은 그림 옆의 **검사 결과 칸**이다.

> 틀린 판에서도 값 범위 검사·단위 검사는 ✓로 통과한다. ✗는 대조 검사에서만 난다.
> 이 대비가 "조용히 틀린다"의 전부다.

| 패턴 | 보여주는 것 | 검출 |
|---|---|---|
| 1. 자기모순 | "사건 없음" 음영 위에 사건 점이 찍힘 | 자동 — 음영∩데이터 |
| 5. 색 정반대 | 범주 색이 뒤바뀌고, 범주 아닌 것에 범주 색이 쓰임 | 자동 — 상수 대조 |
| 7. 겹침 | 반복 단위를 겹쳐 "한 번"과 "매번"이 같은 그림이 됨 | 사람 확인 |

### 탭 2 — 데이터 탐색

`.png`로 답할 수 없는 동작 네 가지를 그대로 넣는다.

| 동작 | 답하는 질문 |
|---|---|
| 조건 켜고 끄기 | 이 차이가 조건 때문인가 |
| 드래그로 구간 확대 | 뭉쳐 보이는 저 구간 안은 어떤가 |
| 호버로 값 읽기 | 저 점이 정확히 몇인가 |
| 구간 통계 | 눈에 보이는 차이가 수치로도 나오나 |

## 산출물

```
demo/
├── 00_설계목표.md          ← 이 파일
├── index.html              ← 자기완결 뷰어 (탭 2개)
└── 개념도_포맷흐름.svg      ← .svg 역할의 예 (구조만, 값 없음)
```

**재현:** `demo/index.html`을 브라우저로 연다. 빌드·설치·통신 없음.

## 한계 (미리 적는다)

- **가상 데이터다.** 여기서 보이는 차이는 실제 관측이 아니라 시드로 만든 것이다.
- 패턴 3(글자 잘림)·4(폰트 깨짐)는 넣지 않았다 — 렌더 환경에 따라 재현이 갈려서
  데모로 삼기에 부적절하다.
- 탭 2는 **탐색 도구의 모양**을 보여줄 뿐, 여기서 본 것은 결론이 아니다. 실제 작업에서는
  `.md`나 `.png`로 옮겨 적기 전까지 기록이 아니다.
